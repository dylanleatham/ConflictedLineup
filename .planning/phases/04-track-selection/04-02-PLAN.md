- Return null for artists not found (caller handles skip logic)

1. Service accepts SpotifyClient from caller (token-based instantiation)

- Catch APIException with 429 status
- Read Retry-After header, wait, then retry
- Max 3 retries per call

Create SpotifyRecentReleasesService implementing ISpotifyRecentReleasesService interface.

Key behaviors per CONTEXT.md:
- "Recent" means from artist's most recent album/EP/single (last album cycle)
- Prioritize singles over album deep cuts (singles more likely played live)
- All release types count: albums, EPs, singles
- If no recent releases, return empty list (orchestrator will backfill with more top tracks)

Implementation details:
1. GetRecentTracksAsync(ISpotifyClient spotify, string artistId) returns List<TrackInfo>
2. Use Artists.GetAlbums with IncludeGroups.Album | IncludeGroups.Single
3. Albums are returned newest first by default
4. Get tracks from the most recent release:
   - If it's a single: return all tracks (usually 1-3)
   - If it's an album: return tracks sorted by popularity, take top 3
5. Use Albums.GetTracks endpoint to fetch track list
6. Market parameter: "US"

Prioritization logic:
- Check if most recent item is a single -> use its tracks
- If album, prefer tracks that were released as singles (higher popularity usually)
- Take up to 3 tracks total

```csharp
public interface ISpotifyRecentReleasesService
```
