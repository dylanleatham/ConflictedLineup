Create SpotifyUserLibraryService implementing ISpotifyUserLibraryService interface.

Key behaviors per CONTEXT.md:
- Sources: Saved tracks + user-created playlists only (not followed playlists)
- If fewer than 3 familiar tracks found, use fewer (don't backfill)
- Limit scanning for large libraries (per RESEARCH.md: 500 saved tracks + 50 playlists max)

Implementation details:

1. GetFamiliarTracksAsync(ISpotifyClient spotify, string artistId) returns List<TrackInfo>

2. Scan saved tracks:
   - Use Library.GetTracks with pagination (50 per page)
   - Use Paginate() not PaginateAll() (memory efficient per RESEARCH.md)
   - Break after scanning 500 tracks OR finding 3 matching tracks
   - Match by checking if any artist on track has matching ID

3. Scan user playlists (only if < 3 found from saved tracks):
   - Use Playlists.CurrentUsers to get user's playlists
   - Filter to owner == current user (skip followed playlists)
   - Limit to first 50 playlists
   - For each playlist, use Playlists.GetItems with pagination
   - Limit to 200 tracks per playlist
   - Look for tracks with matching artist ID

4. Return up to 3 TrackInfo objects

Create SpotifyTrackService implementing ISpotifyTrackService interface. This is the main orchestrator.

Key behaviors per CONTEXT.md:
- Artist-by-artist processing (not parallel to avoid rate limits)
- Deduplication across categories using Track IDs (TRACK-04)
- Skip artists with no Spotify match, track in skipped list (TRACK-05)
- If no recent releases, backfill with additional top tracks
- If fewer than 3 familiar tracks, use fewer (don't backfill)

Implementation:

```csharp
public interface ISpotifyTrackService
{
    Task<TrackSelectionResponse> SelectTracksAsync(
        List<string> artistNames,
        string accessToken,
        IProgress<ArtistProgressUpdate>? progress = null);
}
```

SelectTracksAsync flow:
1. Create SpotifyClient from accessToken
2. Get current user ID (for playlist filtering)
3. For each artist name:
   a. Search artist -> if null, add to skipped list, continue
   b. Fetch familiar tracks (user library)
   c. Fetch top tracks (3)
   d. Fetch recent tracks (3 from latest release)
   e. If recent tracks < 3, fetch additional top tracks to backfill (up to 6 total from top)
   f. Deduplicate across all categories using HashSet<string> of track IDs
   g. Build ArtistTrackResult
   h. Report progress
4. Return TrackSelectionResponse with all artists and skipped

Deduplication priority: familiar > top > recent (per RESEARCH.md example)

```csharp
private List<TrackInfo> DeduplicateTracks(
    List<TrackInfo> familiar,
    List<TrackInfo> top,
    List<TrackInfo> recent,
    out List<TrackInfo> dedupedFamiliar,
    out List<TrackInfo> dedupedTop,
    out List<TrackInfo> dedupedRecent)
{
    var seen = new HashSet<string>();
    dedupedFamiliar = familiar.Where(t => seen.Add(t.SpotifyTrackId)).ToList();
    dedupedTop = top.Where(t => seen.Add(t.SpotifyTrackId)).ToList();
    dedupedRecent = recent.Where(t => seen.Add(t.SpotifyTrackId)).ToList();
    return dedupedFamiliar.Concat(dedupedTop).Concat(dedupedRecent).ToList();
}
```
