  </files>
  <action>
1. Create `frontend/src/auth/SpotifyAuthConfig.ts`:
   - Import TAuthConfig from react-oauth2-code-pkce
   - Export spotifyAuthConfig object with:
     - clientId: import.meta.env.VITE_SPOTIFY_CLIENT_ID (string, empty string fallback)
     - authorizationEndpoint: 'https://accounts.spotify.com/authorize'
     - tokenEndpoint: 'https://accounts.spotify.com/api/token'
     - redirectUri: `${window.location.origin}/callback`
     - scope: 'user-read-private user-read-email playlist-modify-public playlist-modify-private playlist-read-private'
     - decodeToken: false (CRITICAL - Spotify tokens are opaque, not JWTs)
     - autoLogin: false (show landing page first per CONTEXT.md)
     - storage: 'local' (persist across browser sessions per CONTEXT.md)
     - onRefreshTokenExpire: redirect to '/?session_expired=true'

2. Create `frontend/src/auth/AuthProvider.tsx`:
   - Import AuthProvider from react-oauth2-code-pkce
   - Import spotifyAuthConfig
   - Create wrapper component that renders library's AuthProvider with config
   - Export as named export AuthProvider

3. Update `frontend/src/main.tsx`:

   - Wrap App component with AuthProvider
  </action>

<task type="auto">
  <name>Task 3: Create useAuth hook with profile fetching</name>
  <files>
    frontend/src/auth/useAuth.ts
    frontend/src/auth/index.ts
  </files>
  <action>
1. Create `frontend/src/auth/useAuth.ts`:
   - Import useAuth as useOAuthContext from react-oauth2-code-pkce
   - Import useState, useEffect from React
   - Import SpotifyProfile, AuthState from ./types

   - Create fetchSpotifyProfile async function:
     - Takes accessToken string
     - Fetches from 'https://api.spotify.com/v1/me' with Authorization header
     - Returns SpotifyProfile on success
     - Throws on non-ok response

   - Export useAuth hook that:
     - Gets token, login, logOut, loginInProgress, error from useOAuthContext()
     - Manages profile state (SpotifyProfile | null)
     - Manages isLoadingProfile state
     - useEffect that fetches profile when token exists and profile is null
       - On success: setProfile(data)
       - On error: setProfile(null) (per CONTEXT.md: continue with generic avatar)
     - Returns AuthState object:
       - isAuthenticated: !!token
       - isLoading: loginInProgress || isLoadingProfile
       - profile
       - error: error || null
       - login
       - logout: logOut (rename for consistency)
       - token

2. Create `frontend/src/auth/index.ts` barrel export:
   - Export { AuthProvider } from './AuthProvider'
   - Export { useAuth } from './useAuth'
   - Export * from './types'
  </action>
  <verify>
    - `frontend/src/auth/useAuth.ts` contains fetchSpotifyProfile function
    - `frontend/src/auth/useAuth.ts` handles profile fetch error gracefully (sets null)
    - `frontend/src/auth/index.ts` exports AuthProvider, useAuth, and types
    - `npm run build` succeeds
  </verify>
  <done>useAuth hook fetches profile on auth, handles errors gracefully, exports clean API via barrel</done>
</task>
