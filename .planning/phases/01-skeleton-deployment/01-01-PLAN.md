  <action>
Create Docker configuration for both local development (hot reload) and production builds:

1. Create `frontend/Dockerfile` (production multi-stage):
   - Build stage: node:24-alpine, npm ci, npm run build
   - Production stage: nginx:alpine, copy dist to /usr/share/nginx/html
   - Copy nginx.conf for SPA routing
   - Expose port 80

2. Create `frontend/Dockerfile.dev` (development with hot reload):
   - FROM node:24-alpine
   - WORKDIR /app
   - COPY package*.json, npm install
   - COPY source
   - EXPOSE 5173
   - CMD ["npm", "run", "dev"]

3. Create `frontend/nginx.conf`:
   - Serve static files from /usr/share/nginx/html
   - Try files then fall back to index.html for SPA routing
   - Gzip compression enabled

4. Create `backend/Dockerfile` (production multi-stage):
   - Build stage: mcr.microsoft.com/dotnet/sdk:9.0, restore, build, publish
   - Runtime stage: mcr.microsoft.com/dotnet/aspnet:9.0
   - Expose port 8080
   - ENTRYPOINT dotnet ConflictedLineup.Api.dll

5. Create `backend/Dockerfile.dev` (development with hot reload):
   - FROM mcr.microsoft.com/dotnet/sdk:9.0
   - WORKDIR /app
   - COPY csproj, dotnet restore
   - COPY source
   - EXPOSE 8080
   - CMD ["dotnet", "watch", "run", "--project", "src/ConflictedLineup.Api", "--urls", "http://+:8080"]

6. Create `docker-compose.yml` (production):
   - frontend service: build from ./frontend, port 80:80
   - backend service: build from ./backend, port 8080:8080

7. Create `docker-compose.dev.yml` (development with hot reload):
   - frontend service:
     - build: context ./frontend, dockerfile Dockerfile.dev
     - volumes: ./frontend:/app, /app/node_modules (anonymous volume)
     - environment: CHOKIDAR_USEPOLLING=true, VITE_API_URL=http://localhost:8080
     - ports: 5173:5173
   - backend service:
     - build: context ./backend, dockerfile Dockerfile.dev
     - volumes: ./backend:/app
     - environment: ASPNETCORE_ENVIRONMENT=Development, DOTNET_USE_POLLING_FILE_WATCHER=true, ASPNETCORE_URLS=http://+:8080
     - ports: 8080:8080

8. Create `.env.example` at root:
   - # Local development environment variables
   - VITE_API_URL=http://localhost:8080

9. Update `.gitignore` (create if not exists) to include:
   - .env.local
   - .env
   - node_modules/
   - dist/
   - bin/
   - obj/
   - .vs/
   - *.user
  </action>
