## Local Development Verification

1. Start local development environment:
   ```bash
   docker compose -f docker-compose.dev.yml up --build
   ```

2. Verify frontend:
   - Open http://localhost:5173
   - Should see "Conflicted Lineup" heading
   - Modify frontend/src/App.tsx text
   - Browser should auto-refresh showing changes

3. Verify backend:
   ```bash
   curl http://localhost:8080/api/health
   ```
   - Should return: {"status":"Healthy","timestamp":"..."}
   - Modify backend code, should auto-recompile

4. Stop containers:
   ```bash
   docker compose -f docker-compose.dev.yml down
   ```

## CI/CD Verification

5. Make a small change and push to main:
   ```bash
   # Add a comment to any file
   git add .
   git commit -m "test: verify CI/CD pipeline"
   git push origin main
   ```

6. Monitor GitHub Actions:
   - Go to repository -> Actions tab
   - Both "Deploy Backend to Azure" and "Deploy Frontend to Azure" should run
   - All jobs should pass (green checkmarks)

## Production Verification

7. Verify frontend via custom domain:
   - Open https://YOUR-CUSTOM-DOMAIN in browser
   - Should see "Conflicted Lineup" heading
   - Check SSL certificate is valid (lock icon)

8. Verify backend via custom domain:
   ```bash
   curl https://YOUR-CUSTOM-DOMAIN/api/health
   ```
   - Should return: {"status":"Healthy","timestamp":"..."}

9. Verify Key Vault integration:
   - Azure Portal -> conflictedlineup-api -> Configuration
   - PlaceholderSecret should show "@Microsoft.KeyVault(...)"
   - Azure Portal -> conflictedlineup-api -> Log stream
   - No Key Vault errors in startup logs
