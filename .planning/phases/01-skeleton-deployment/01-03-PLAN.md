     - runs-on: ubuntu-latest
     - Setup Node.js 24.x with npm caching (cache-dependency-path: ./frontend/package-lock.json)
     - npm ci in frontend directory
     - npm test in frontend directory (CI=true environment)

     - runs-on: ubuntu-latest
     - permissions: id-token: write, contents: read

     - Login to Azure using OIDC (azure/login@v2)
     - Deploy using azure/webapps-deploy@v3 to conflictedlineup-web
     - Package: ./frontend/dist
     - Logout from Azure (if: always())

Key configuration:

- Working directory for npm commands: ./frontend

<task type="auto">
  <name>Task 2: Add startup command configuration for Node.js App Service</name>
  <files>
    frontend/serve.json
  </files>
  <action>
Azure App Service with Node.js runtime needs configuration to serve static files properly:

1. Create `frontend/serve.json` for static file serving configuration:
   ```json
   {
     "rewrites": [
       { "source": "**", "destination": "/index.html" }
     ],
     "headers": [
       {
         "source": "**/*.@(js|css)",
         "headers": [
           { "key": "Cache-Control", "value": "public, max-age=31536000, immutable" }
         ]
       }
     ]
   }
   ```

2. Update frontend/package.json to add serve as a dependency and start script:
   - Add "serve": "^14.0.0" to dependencies
   - Add "start": "serve dist" to scripts

This ensures Azure App Service can serve the SPA correctly with:
- Client-side routing support (all routes serve index.html)
- Proper cache headers for static assets
  </action>
  <verify>
Configuration exists:
- `ls frontend/serve.json`
- `grep -q "serve" frontend/package.json`
  </verify>
  <done>Static file serving configuration added for Azure App Service</done>
</task>
