  <action>
1. Add Anthropic SDK package to .csproj:
   - Add `Anthropic.SDK` NuGet package (official C# SDK)

2. Create Models/ExtractionModels.cs with:
   - `ArtistExtractionResult` record: Artists (list of ArtistInfo), Warning (optional string for partial results)
   - `ArtistInfo` record: Name (string), Confidence (string: "high" | "uncertain")
   - `FestivalSearchResult` record: Artists (list of ArtistInfo), FestivalName (string), Year (int), Sources (list of string)
   - `PosterExtractionRequest` record: ImageBase64 (string), MediaType (string)
   - `FestivalSearchRequest` record: FestivalName (string), Year (optional int)

3. Create Services/ClaudeService.cs with:
   - Interface `IClaudeService` with methods:
     - `Task<ArtistExtractionResult> ExtractArtistsFromPosterAsync(string imageBase64, string mediaType)`
     - `Task<FestivalSearchResult> SearchFestivalLineupAsync(string festivalName, int? year)`
   - Implementation `ClaudeService`:
     - Constructor takes IConfiguration, reads ANTHROPIC_API_KEY from config
     - Creates Anthropic client
     - `ExtractArtistsFromPosterAsync`:
       - Read prompt from Prompts/poster-extraction.txt using File.ReadAllTextAsync
       - Call Claude Vision API with base64 image
       - Parse JSON response into ArtistExtractionResult
       - Handle errors gracefully, return partial results with warning if parsing fails
     - `SearchFestivalLineupAsync`:
       - Read prompt from Prompts/festival-search.txt
       - Replace {FESTIVAL_NAME} and {YEAR} placeholders
       - Call Claude with web_search tool enabled
       - Parse response into FestivalSearchResult
   - Use model "claude-sonnet-4-5-20250514"
   - Max tokens: 2048 for both
  </action>

    - `dotnet build` succeeds in backend/src/ConflictedLineup.Api
    - ClaudeService.cs exists with both methods
    - ExtractionModels.cs contains all required records
  </verify>

  <name>Task 2: Create extraction controller and prompt files</name>
  <files>
    backend/src/ConflictedLineup.Api/Controllers/ExtractionController.cs

  <action>
1. Create Prompts directory and prompt files:

   poster-extraction.txt:
   ```
   Analyze this festival poster image and extract all artist/performer names you can identify.

   Return a JSON object with this exact structure:
   {
     "artists": [
       {"name": "Artist Name", "confidence": "high"},
       {"name": "Another Artist", "confidence": "uncertain"}
     ],
     "warning": null
   }

   Guidelines:
   - List ALL visible artist names, even if you're uncertain about spelling
   - Mark names as "uncertain" if the text is hard to read or stylized
   - Include headliners and smaller acts
   - If the image quality is poor or text is unreadable, set warning to describe the issue
   - Return ONLY the JSON, no other text
   ```

   festival-search.txt:
   ```
   Search for the lineup of {FESTIVAL_NAME} {YEAR}.

   Return a JSON object with this exact structure:
   {
     "festivalName": "Official Festival Name",
     "year": 2026,
     "artists": [
       {"name": "Artist Name", "confidence": "high"}
     ],
     "sources": ["URL of source"]
   }

   Guidelines:
   - Find the most recent/upcoming lineup if year is not specified
   - Include all announced artists (headliners and undercard)
   - Mark confidence as "uncertain" only if conflicting sources
   - Include source URLs for verification
   - Return ONLY the JSON, no other text
   ```

2. Create Controllers/ExtractionController.cs:
   - `[ApiController]` and `[Route("api/extraction")]`
   - Constructor injects IClaudeService
   - `POST /api/extraction/poster`:
     - Accepts PosterExtractionRequest (JSON body with base64 image)
     - Validates image size (base64 string length < 7MB to account for ~5MB raw)
     - Validates media type is image/jpeg, image/png, or image/webp
     - Calls ClaudeService.ExtractArtistsFromPosterAsync
     - Returns ArtistExtractionResult
   - `POST /api/extraction/festival`:
     - Accepts FestivalSearchRequest (JSON body)
     - Validates festival name is not empty
     - Calls ClaudeService.SearchFestivalLineupAsync
     - Returns FestivalSearchResult

3. Update Program.cs:
   - Add `builder.Services.AddControllers()`
   - Register IClaudeService/ClaudeService as scoped
   - Add `app.MapControllers()` after existing routes
   - Add CORS origin for production domain (keep localhost for dev)
   - Ensure prompts directory is copied to output (add ItemGroup in csproj if needed)

4. Update .csproj to include Prompts as content:
   ```xml
   <ItemGroup>
     <Content Include="Prompts\**\*" CopyToOutputDirectory="PreserveNewest" />
   </ItemGroup>
   ```
